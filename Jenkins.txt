To deploy the code which was created by developer we use CI/CD pipeline
CI- Continuous Integration
CD-Continuous Deliver/Continuous Deployment
Continuous deliver - if we do manually with maven commands
Continuous Deployment - it is automation using maven tool

First developer will write the code and push to GitHub. 
From GitHub, we will build, test and deploy through CI/CD
CI means it is a combination of Continuous build + Continuous test
Once the code was ready in Github, the build will compile the code and test 
Here we are using the Jenkins tool for CI/CD
For deploying the application we need three serves
1. Jenkins Server - to build and test the code and create the package(war/jar/ear) file
2. Application server - to run the application using tomcat
3. Nexus server - to store the artificats

To create the repositoryin Nexus to store the artificats

And In the Jenkins Dashboard, we can create the new freestyle Project 
In configure,

select the source code management - Connect and manage your code repository to automatically pull the latest code for your builds.
    Repository URL - provide which repo your connecting from Github that repo https url and branch name
    credentials - if the repo is public none or if private create the credentials using Github credentials
	Branches to build - branch name In which branch the code is present

Triggeres - Set up automated actions that start your build based on specific events, like code changes or scheduled times.
   If we select GitHub hook trigger for GITScm polling - We need to configure the webhook in GitHub for that repo
   If we select PollSCM - its like crontab entry * * * * *

Build Steps - Automate your build process with ordered tasks like code compilation, testing, and deployment.
   For configuring the build step, we need to setup the maven tools by using Maven Installation option and select the version as lates
   Once tools setup and under Build steps select Invoke top-level Maven targets
   maven version as what we created while Maven installation
   Goals means maven commands - clean install
   
To integrate the nexus with jenkins we need to install plugin  Nexus Artifact uploader and configure in build steps 
   Select Nexus artifact uploader
   Nexus version : Nexus3
   Protocol: HTTP
   Nexus URl: hostname:8081
   credentials: Nexus credentials
   groupID: from Pom.xml file
   Version: from Pom.xml file
   Repository: nexus repo name 
   ArtifactID: from Pom.xml file 
   Type:file format (war)
   File: target/artifactid-version.war   format
   
Once you give all inputs the run the build now, it will store the artifcats in nexus repository
